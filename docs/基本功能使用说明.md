# Eread 基本功能使用说明

版本：1.0.0
定位：10 分钟上手

## 1. 首次配置

1. 设置 → 模型：填写接口地址、API Key、模型名；
2. 设置 → 悬浮窗：授予悬浮窗权限；选择截屏方式；
3. 运行页：选择 Legado 或 Readest 模式，点「启动悬浮窗」；
4. 阅读页出现悬浮球后，点球展开面板。

## 2. 查询人物

面板输入人名（不少于 2 字），点搜索。

结果包括：

- 最早出现章节；
- 命中片段（点击跳转或复制）；
- AI 概述、详细档案、人物关系入口。

## 3. 截屏识别当前页

点「截屏识别当前页」：

1. 自动隐藏面板并截屏；
2. 识别页面文字；
3. 定位章节、校准页码；
4. 抽取本页人名，显示为胶囊，点击直接查询。

OCR 识别与屏幕录制两种方式在设置中选择；两种方式可分别开启 AI 辅助。

## 4. 人名歧义

「雷蒙」可能对应「雷蒙德三世」「雷蒙·杜·皮伊」等多个全名。

系统会列出候选，需要每次手动选择，不会自动记忆。

## 5. 页码校准

面板 → 页码校准：

- 手动填入阅读器页码；
- 截屏校准：自动读页码并定位；
- 重建人名索引：扫描全书，建立人物实体，减少同名歧义。

## 6. 关系网

1. 选择主人物；
2. 选择一位或多位次人物；
3. 点「生成关系列表」。

结果只保留所选次人物，并自动把反向关系写入次人物档案。
「关系时间线」可查看已保存的关系清单。

## 7. 数据与档案

数据页按书管理档案：

- 最新概述；
- 详细档案；
- 人物关系；
- 删除。

长按条目可多选导出、系统分享或删除。

## 8. 个性化

设置 → 个性化 → 提示词：

- AI 文风与结构；
- 概述温度、最大 token、关系温度；
- 回读分段密度；
- 命中展示上限、每章命中上限、别名阈值、定位候选章；
- 共现距离、共现片段数、补档回看章；
- 人名长短、近似名编辑距离、额外身份词。

每项右侧问号有说明；底部可保存或恢复默认。

## 9. 常见问题

**识别不到文字**：检查无障碍/录屏权限、画面亮度、是否受版权保护。

**命中数偏少**：重新截屏识别一次，确认位置已更新到当前页。

**人物档案重复**：先重建人名索引，再打开数据页，系统会合并近似名。

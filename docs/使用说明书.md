# Eread 人物速查 使用说明书

版本：1.0.0

## 摘要

Eread 是面向长篇小说阅读的独立辅助工具，用于回溯人物出场、生成概述与详细档案、梳理人物关系。本文档说明安装、配置、两种读取模式、截屏识别、人名消歧、检索命中、页码校准、关系网、数据管理与个性化参数。

## 第一章 安装与配置

### 1.1 安装

安装 Eread 1.0.0。首次启动会请求通知权限，用于录屏授权提示。

### 1.2 权限

| 权限 | 用途 |
| --- | --- |
| 悬浮窗 | 悬浮球与查询面板 |
| 无障碍 | OCR 截屏识别 |
| 录屏 | 屏幕录制取帧 |
| 通知 | 录屏与授权提示 |

### 1.3 模型

设置 → 模型：接口地址、API Key、模型名、推理等级。API Key 使用 Keystore 加密保存。

## 第二章 读取方式

### 2.1 Legado 模式

通过 legado 的 Web 服务（默认 1122 端口）读取书架、章节与阅读位置。位置自动同步，片段可跳转回 legado。

### 2.2 Readest 模式

导入同一本 EPUB/TXT，使用本地全文检索。位置来自截屏识别或手动选章；片段点击为复制。

## 第三章 查询

输入人名后，系统从当前阅读位置向前回溯：

1. 本地精确检索命中；
2. 解析人名实体；
3. 判定缓存、增量或回读；
4. 生成概述并写入档案。

命中数按当前阅读位置之前的章节统计；结果列表按设置的上限抽样展示。

## 第四章 截屏识别

### 4.1 两种方式

- OCR 识别：无障碍截屏，速度快，无状态栏提示；
- 屏幕录制：MediaProjection，授权一次可反复取帧，状态栏显示共享中。

### 4.2 流程

截屏 → 裁剪正文 → 文字识别 → 章节定位 → 页码校准 → 人名抽取。

### 4.3 AI 辅助

两种方式各有独立开关；仅在本地匹配分数低时调用模型纠错。纠错文本同时用于定位与抽名。

## 第五章 人名与索引

### 5.1 姓名结构

基名、世次（三世/四世）、分隔结构（·）均保留。

### 5.2 消歧

同一短名对应多个全名时列出候选，每次询问，不自动绑定。

### 5.3 人名索引

页码校准 → 重建人名索引：扫描全书，收录高置信度写法，跳过参考文献与索引章节。

## 第六章 检索命中

- 精确子串匹配，不经过 AI；
- 按当前阅读位置截断；
- 每章命中数、总命中数可配置；
- 结果列表可配置展示上限；
- 别名合并只对短名生效，完整人名不做拆分。

## 第七章 页码校准

手动校准、截屏校准、重建索引三种方式。页码为估算值，取决于排版参数。

## 第八章 关系网

1. 选择主人物；
2. 选择次人物（不含主人物）；
3. 生成关系列表。

生成前会：

- 为无档案人物补充简要概述；
- 扫描全书，找两人在章内最近的一次同段出现；
- 将共现片段加入提示词。

生成后：

- 只保留所选次人物；
- 主人物档案保存正向关系；
- 自动生成反向关系并写入次人物档案；
- 关系时间线可查看已保存清单。

## 第九章 数据管理

书目按书名聚合；同名书的接口档案与本地档案合并。

单卡操作：最新概述、详细档案、人物关系、删除。
长按多选：导出 TXT/Word、系统分享、删除。

## 第十章 个性化参数

设置 → 个性化 → 提示词：

1. AI 文风与结构；
2. 概述温度、概述最大 token、关系温度；
3. 回读分段密度；
4. 命中展示上限、每章命中上限、别名阈值、定位候选章；
5. 共现距离、共现片段数、补档回看章；
6. 人名最短/最长长度、近似名编辑距离、额外身份词。

文风提示词只作用于概述、详细档案与关系生成，不影响 OCR 纠错与人名抽取。

## 第十一章 AI 与隐私

- 仅在主动查询、识别、生成时发送必要片段；
- 截屏仅本机识别；
- 数据保存在应用私有目录，系统备份关闭；
- API Key 加密存储；
- 可随时删除书籍档案与缓存。

## 第十二章 常见问题

**命中数与阅读器不一致**：确认已重新识别当前页；Readest 按整章统计。

**关系显示资料片段不详**：原文没有同段证据，或模型未采用共现片段；可重新生成。

**OCR 误读产生重复人物**：打开数据页会自动按编辑距离合并；也可调大近似名编辑距离。

## 第十三章 限制

- 页码为估算值；
- AI 生成内容可能有误；
- 受版权保护页面可能无法截屏；
- 关系时间线目前为清单视图，不是严格时间轴。
